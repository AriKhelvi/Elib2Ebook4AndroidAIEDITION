# Elib2Ebook для Android

Скачивайте книги, фанфики, ранобэ, мангу и комиксы с литературных сайтов прямо на телефон. Приложение собирает доступные главы в файл, который можно открыть в любимой читалке и читать без интернета. Компьютер и отдельный сервер для скачивания не нужны.

[Скачать APK](https://github.com/AriKhelvi/Elib2Ebook4AndroidAIEDITION/releases/latest) · [Все версии](https://github.com/AriKhelvi/Elib2Ebook4AndroidAIEDITION/releases) · [Telegram-канал разработчиков](https://t.me/elib_fb2_android)

## Что умеет приложение

- Скачивать книги по ссылке: вставьте её вручную или отправьте из браузера через «Поделиться» → «Скачать книгу (E2E)».
- Сохранять текстовые книги в **EPUB, FB2 и TXT**, а мангу и комиксы — в **CBZ**. Формат выбирается для каждой ссылки; для комиксов есть автоматический выбор CBZ.
- Загружать книгу целиком или выбирать диапазон глав по номерам и названиям.
- Сохранять обложки и иллюстрации, отключать загрузку картинок. Дополнительные изображения, аудио и оригинальные файлы доступны там, где это поддерживает загрузчик сайта.
- Обрабатывать несколько ссылок по очереди, показывать ход загрузки и отменять задания.
- Работать в фоне с уведомлением о загрузке.
- Сохранять файлы в «Загрузки/Elib2Ebook» или выбранную папку, открывать их в читалке и отправлять через «Поделиться».
- Хранить историю во вкладке «Книги» и повторять загрузку по сохранённой ссылке.
- Входить на сайты по логину и паролю, если такой вход поддерживается. Сохранённые данные входа хранятся в защищённом хранилище Android.
- Настраивать таймаут, паузу между запросами, прокси и шаблон имени файла.
- Переключать светлую, тёмную, AMOLED- и e-ink-темы, использовать системное оформление.
- Сохранять журнал скачивания и запускать диагностику для разбора ошибок.

## Установка и первый запуск

1. Откройте [последний стабильный релиз](https://github.com/AriKhelvi/Elib2Ebook4AndroidAIEDITION/releases/latest) и скачайте APK из раздела **Assets**.
2. Откройте APK на Android-устройстве. Если система попросит, разрешите установку из выбранного источника.
3. Запустите приложение, вставьте ссылку на книгу и выберите формат.
4. Если сайт требует авторизацию, заполните «Вход на сайт». При необходимости укажите диапазон глав и нажмите «Скачать».
5. Откройте готовую книгу из вкладки «Книги» в установленной читалке.

Для установки заявлена поддержка **Android 7.0 и новее**. APK рассчитан на устройства ARM и ARM64. Интерфейсу нужен системный WebView на базе **Chromium 94 или новее**. Версия Android сама по себе не гарантирует подходящую версию WebView: особенно это важно для старых телефонов, планшетов и электронных читалок.

Сборки с пометкой **Pre-release** предназначены для тестирования. Для обычного использования выбирайте стабильный релиз.

## Возможности и ограничения сайтов

- Наличие сайта в каталоге означает, что для него предусмотрен загрузчик. Сайт может изменить адрес, разметку, API или правила доступа — после этого потребуется обновление приложения.
- Для закрытых материалов могут понадобиться учётная запись, покупка или подписка на самом сайте. Приложение работает с доступом, который предоставляет сайт вашему аккаунту.
- Защита сайта может временно ограничить частые запросы или потребовать проверку в браузере. Пауза между запросами иногда помогает, но не гарантирует доступ.
- Таймаут и пауза решают разные задачи: таймаут даёт серверу больше времени ответить, пауза уменьшает частоту обращений.
- Состав книги зависит от доступных глав и данных сайта. Обложка, серия, номер книги и иллюстрации могут отсутствовать в источнике или потребовать исправления загрузчика.
- Большие книги с сотнями изображений требуют больше памяти, свободного места и времени. Системное энергосбережение может мешать загрузке в фоне.
- После переустановки Android может ограничить управление ранее сохранёнными файлами из приложения; такие файлы можно открыть или удалить через системный файловый менеджер.
- Приложение сохраняет книги в файлы. Для чтения нужна отдельная читалка.

В текущем стабильном выпуске разбираем сообщения об ограничении в 100 глав на Bllate, ошибке загрузки Litgorod, пропущенных иллюстрациях и слишком больших журналах. Также проверяем метаданные серий Litnet, совместимость FB2 с читалками и запуск на отдельных устройствах. Исправления будут отмечаться в описаниях релизов; успешная проверка главной страницы сайта ещё не означает, что книга скачалась полностью.

## Нужны тестировщики

Приложение уже можно пробовать, но проверить все сайты, книги, телефоны и читалки в одиночку невозможно. Нужны люди, которые готовы установить APK, скачать свои книги и рассказать, что получилось.

Особенно полезны проверки длинных книг, иллюстраций, серий, загрузки в фоне, разных форматов и запуска на старых устройствах. Хороший результат тоже важен: если всё скачалось и открылось как надо, напишите об этом.

Если что-то сломалось, сообщите:

- модель устройства, версию Android и приложения;
- ссылку на книгу, выбранный формат и диапазон глав;
- что ожидали получить и что произошло;
- текст ошибки и журнал, если его удалось сохранить.

Журнал скачивания можно сохранить через «Настройки» → «Отладка» → «Сохранить журнал последнего скачивания». В этом же разделе есть отдельная диагностика. Если приложение не запускается или журнал не открывается, опишите это в сообщении — отсутствие журнала не мешает сообщить о проблеме.

**[ТГ-канал разработчиков](https://t.me/elib_fb2_android). Если возникла ошибка — напишите в сообщения каналу.** Регистрация на GitHub для обратной связи не нужна. Если вам удобнее GitHub, можно [создать issue](https://github.com/AriKhelvi/Elib2Ebook4AndroidAIEDITION/issues).

Спасибо всем, кто пробует, присылает журналы и помогает находить ошибки. Вместе сделать приложение удобнее гораздо проще.

## Добавим в будущем

- **Поддержка кастомных зеркал пользователей для регулярно переезжающих сайтов.**
- **Запоминание входа по cookie-файлу сессии** — для сайтов, где это позволяет поддерживать авторизованную сессию.
- **Слайдер задержки между запросами:** нулевая, стандартная, увеличенная и своя задержка. Стандартный режим будет выбран по умолчанию для всех сайтов.
- **Понятные предупреждения о неполной загрузке:** какие главы или изображения не удалось получить.
- **Автоматический журнал запуска:** сохранится, если приложение не смогло открыться, и удалится после успешного запуска.
- **Возобновление прерванной загрузки** без повторного скачивания уже полученных глав.
- **Обновление сохранённых книг:** проверка новых глав и добавление их в книгу.

Это планы развития. Наличие функции в этом разделе не означает, что она уже есть в опубликованном APK; о готовых изменениях будем писать в релизах и Telegram-канале.
