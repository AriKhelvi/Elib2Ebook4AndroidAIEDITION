# Проверки сервисов Android на ПК

Запуск: `dotnet test android/ServiceTests/ServiceTests.csproj -c Release` из корня репозитория.

Тесты подключают исходные `ActivityResults.cs` и `CredentialStore.cs` ссылками. Граница с Android/MAUI
заменена в `PlatformStubs.cs`: проверяются таймаут, поздний ответ диалога, ошибки хранилища,
сохранность списка сайтов и отсутствие паролей в сообщениях об ошибках.

Эти проверки не запускают Android и не проверяют настоящий Keystore, UI-поток или выдачу SAF-разрешений.
Для этого нужны устройство либо эмулятор.

Автодиагностика проверяется теми же исходниками: корректный итог после отмены, предупреждения HTTP/ядра,
включение прошлых журналов без изменения, ограничение размера и исключение base64. Проверки FB2/EPUB используют
настоящие сборщики и искусственно повреждённые файлы: пустые/повторные главы, Unicode, изображения, XML,
manifest/spine и внутренние ссылки. Сетевые запросы и реальное устройство этими тестами не подменяются.
