# SD-карта и отдельная папка журналов

Пользователь выбрал `sd/ranobe/elib`, но экран показывал только `Elib`, а журнал оказался
во внутренней памяти. В 0.2.2 книги и экспорт журналов использовали один `IBookStorage`;
специального перенаправления только журналов не было. `HasTree()` при отсутствии сохранённого
разрешения молча очищал выбор, в том числе при чтении `DestinationLabel`, после чего запись
переходила в «Загрузки». По одному скриншоту нельзя доказать потерю разрешения у пользователя.
Отсутствие CBZ из присланного журнала объясняется отдельной ошибкой сборки до экспорта.

## Изменения

- Выбранный URI сохраняется при потере доступа. Запуск и экспорт проверяют его;
  вместо скрытого переключения показывается понятное сообщение. Чтение подписи не меняет настройки.
- Системные папки показываются с носителем и полным относительным путём. UUID неизвестного
  внешнего тома не объявляется SD-картой: это может быть USB. Непрозрачные ID других провайдеров
  не преобразуются в файловые пути; уже декодированный ID не декодируется повторно.
- В «Отладке» добавлена независимая папка журналов, по умолчанию `Загрузки/Elib2Ebook/Logs`.
  Экспорт журналов скачивания, запуска и диагностики использует её. Книги сохраняются по прежней настройке.
- Выбор/сброс папки отпускает только прежнее разрешение этого назначения. Если им ещё пользуется
  второе назначение, разрешение остаётся. Посторонние разрешения приложения не отзываются.
- Проверка сохранения книг в полной диагностике продолжает проверять папку книг; сам отчёт
  пишется в папку журналов. Папки отдельно указаны в диагностике, назначение журнала — в шапке экспорта.
- Ошибка доступа перед запуском обрабатывается уведомлением и освобождает занятый запуск;
  она не выходит необработанной в Blazor. Для папки журналов запрашиваются необходимые права Android 7–9.

## Проверки

236 тестов сервисов прошли: независимый экспорт при недоступной папке книг, отсутствие запасной
записи в папку книг при отказе журналов, повторный запуск после ошибки, разделение разрешений,
пути внутреннего/внешнего хранилища, Unicode и специальные символы.
Android-специфичные SAF-вызовы проверяются компиляцией CI; физическая SD-карта в этой среде не проверялась.
