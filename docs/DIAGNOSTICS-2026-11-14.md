# Разбор полного прогона диагностики 0.2.2-dev.2

Источник: присланный владельцем `E2E-diagnostics-20261114-232954.txt`, коммит `6ba0513`. Прогон завершился за 18:24. По таблице 86 случаев: 18 OK, 4 предупреждения, 4 ограничения доступа, 16 ошибок, 3 таймаута, 41 пропуск. Старое итоговое число 42 OK включало 24 локальные проверки приложения; новая сводка отделяет их от сайтов.

## Подтверждённые причины

- Acomics: HTTP 200 с региональной заглушкой без метаданных комикса; это не успешно полученная книга. Вместо NullReferenceException нужен явный отказ сайта.
- LibKing: текст перенесён из `#book` в `#read`.
- HogwartsNet: у выбранного короткого произведения есть `#chap_text`, но нет списка глав. Поддержан одиночный текст.
- Readli: при загрузке обложки адрес подключения по IP ошибочно считался публичным адресом изображения, из-за чего защита заголовков удаляла Host. Теперь публичное имя сохраняется отдельно от маршрута соединения. Проверка сертификатов и очистка заголовков внешних изображений не ослаблены.
- Литсовет: старый пример удалён. У нового изменены блоки автора, обложки, оглавления и текста (`.reader-text`). Поддержана текущая и прежняя разметка; отсутствующие главы не выдаются за успех.
- Litnet: выбранное произведение требует входа для 18+. Анонимная диагностика должна показывать ограничение доступа, а не ошибку парсера.
- MangaLib: у прежнего примера API вернул пустое оглавление и признак лицензии. Это не доказательство поломки JSON-парсера.
- MyBook: при импорте EPUB исходные ссылки между файлами оставались со старыми путями, а сборщик назначал главам новые имена. Импорт теперь создаёт уникальные якоря по пути исходного файла, а сборщик EPUB восстанавливает ссылки между получившимися главами и сносками. Проверка структуры EPUB не ослаблена.
- Ranobes: старый необязательный запрос проверки читался как JSON даже при HTTP 404. Требуется проверять статус и не скрывать ограничения сайта.
- RanobeHub: сайт перешёл на новую разметку и публичный читательский API. Первая часть выбранного примера содержит только иллюстрации; текстовый сценарий начинает со второй части.

## Обновлённые примеры

- Rulate: <https://tl.rulate.ru/book/273770>, ссылка найдена на главной <https://tl.rulate.ru/>. Проверено скачивание одной публичной главы и создание FB2/EPUB, временные файлы удалены. Прежний `209502` вернул HTTP 410.
- Литсовет: <https://litsovet.ru/books/1002083-vsyakoe-sluchaetsya>, источник — авторский пост <https://litsovet.ru/blogs/9649-nachalo-polozheno>. Карточка и первая глава вернули HTTP 200 и содержат текст. Прежний `1002110-zhiv` вернул HTTP 404.
- Bookstime: <https://bookstime.ru/> теперь содержит материалы о школьной программе, а не прежний книжный каталог; диагностический пример `/book-card/2551` получает явный пропуск с причиной.
- MangaLib: <https://mangalib.me/ru/18406--nan-hao-shang-feng> и <https://mangalib.org/ru/18406--nan-hao-shang-feng>, ссылка найдена в публичном каталоге MangaLib. API вернул карточку без признака лицензии, 130 глав и первую главу с одним изображением. Загрузка самого изображения с CDN не подтверждена: таймаут соединения для `.me`, недоверенная цепочка в локальном curl для `.org`.

## Границы вывода

ЛитРес и Neobook завершились TLS EOF — соединение оборвалось во время рукопожатия. Это не отказ из-за просроченного сертификата и не подтверждённый дефект парсера. Отказы 403/429, недоступные 404/410, таймауты и пропуски не считаются успешной проверкой загрузчика. Прогон анонимный и не проверяет доступ к купленным книгам.

Временная программа исследования MyBook завершилась с необработанным исключением и показала диалог Windows; процесс остановлен. В консольные пробы добавлены перехват исключений, лимит времени и очистка временных файлов в `finally`, без изменения системных настроек Windows.

Живой прогон RanobeHub создал FB2 и EPUB из двух публичных частей; временные книги удалены. Полная проверка Литсовета остановилась на сетевой загрузке обложки, хотя карточка и текст доступны отдельными запросами. Проверка MyBook ограничена офлайн-пересборкой EPUB: новый сетевой запрос завершился TLS timeout. Блок покупки внутри `.reader-text` Литсовета подтверждён на <https://litsovet.ru/books/1000101-tropa-zabveniya/read> и теперь даёт ограничение доступа; платёжная модалка вне текста не мешает бесплатным главам.

## Проверки изменений

- Полный набор ядра: 596/596; Android-сервисы: 159/159. Среди регрессий — ссылки и сноски EPUB между исходными файлами, разделение одного XHTML, якоря `body/html`, ограничения доступа и сохранение заголовков Readli только для собственного origin.
- CoreSmoke собран без предупреждений; офлайн-сверка каталога с реестром загрузчиков прошла. Преднамеренно некорректный URL дал перехваченную UriFormatException, код выхода 1 и не оставил временных папок.
- Локальный Android Debug заблокирован отсутствующим workload `maui-android` (NETSDK1147); Android Debug/Release проверяются workflow ветки. Это ограничение среды, а не успешная локальная сборка APK.
