# Проверка новых сообщений тестировщиков

Проверки выполнены 12 ноября 2026 года на ПК тем же `BookPipeline`, загрузчиками и сборщиками, которые использует Android-приложение. Обычный публичный доступ без логина, стандартная задержка 0,6–1,5 секунды. Это не проверка запуска APK на устройстве.

## Rulate: книга 209502

[Пример пользователя](https://tl.rulate.ru/book/209502): две страницы оглавления, 167 уникальных глав. Загрузчик обработал все 167, включая страницу после сотой главы. Сайт предоставил тексты глав 1–51; для 52–167 вернул отсутствие доступа. Эти 116 глав отмечены предупреждениями, в книгу не включены.

Созданы FB2 и EPUB с 51 непустой главой в правильном порядке и обложкой. Независимая проверка: 23/23 — официальная XSD FB2, структура EPUB, CRC архива, manifest/spine, XML, ссылки и изображения. Полный проход занял около трёх минут. На этом примере можно подтвердить проход всего оглавления, но нельзя проверить сохранение более 100 текстов без доступа к закрытым главам.

## Rulate: журнал книги 129557

В присланном журнале [«Лунное путешествие (LN)»](https://tl.rulate.ru/book/129557?Chapter_page=7) остановилось после 100 записей оглавления. Последняя имела название «Часть 95»: номера в названиях повторяются, поэтому они не равны количеству записей.

Текущий загрузчик получил все 609 уникальных записей. Дополнительно проверены настоящие тексты 100-й и 101-й записей. Последняя, 609-я, без входа недоступна. Параметр `Chapter_page` исходной ссылки не ограничивает книгу: сначала собирается полное оглавление, затем применяется диапазон приложения.

Диапазон 100–101 сохранён в FB2 и EPUB без предупреждений. Независимая проверка: 28/28 — обе главы в правильном порядке, FB2 соответствует XSD, EPUB структурно корректен. После удаления служебного абзаца текст совпал с ранее скачанными HTML в обоих форматах при исключении пробельных символов. Все 609 текстов в этой проверке не скачивались.

Ссылка в конце каждой части присутствует в ответе сайта: отдельный `<p>` с URL текущей главы. Очистка удаляет только такой завершающий абзац с точным адресом скачиваемой главы. Другие адреса, авторские подписи, ссылки внутри текста и изображения сохраняются. Общая очистка ссылок других сайтов по этому примеру не выполняется.

## Rulate: полный проход на Android, 13 ноября

Журнал владельца для книги 129557, APK `0.2.1-dev.34`, коммит `91644c6`: 279 попыток глав с 05:14:48 до 05:20:01 МСК. Первые 158 записей обработаны без предупреждений об отсутствии доступа. На 159-й записи — «Часть 154. Том 3. Земля», ID `26108831` — API сообщил об отсутствии доступа; такие ответы повторились 120 раз подряд. Следующий запрос завершился HTTP 403. Генерация EPUB не началась: сборщик вызывается после завершения загрузчика. Это подтверждает прохождение границы 100 глав, но не сохранение полной книги. Причину последнего HTTP 403 журнал не раскрывает.

В публичной разметке второй страницы оглавления подтверждён явный признак: у `26108831` есть `span.disabled` с `title="Вы не можете скачивать перевод этой главы."`, отсутствует активное действие скачивания. Предыдущая запись `26108830` содержит активную кнопку «Получить готовый перевод.» и `download_chapter[]`. Ссылка в названии `/ready_new` есть в обоих случаях, а цена сама по себе не определяет доступ текущего пользователя.

Загрузчик сохраняет этот признак вместе с ID и названием. Диапазон применяется к полному оглавлению, после чего явно недоступные главы пропускаются с предупреждением, без запроса `readyajax`. Противоречивая разметка с активной кнопкой или выбором скачивания проверяется через API. Неизвестные признаки не считаются запретом. Поздний HTTP 403 по-прежнему останавливает генерацию; автоматическое сохранение незавершённой книги не добавлено.

Проверки исправления: 277 тестов ядра прошли, включая 16 новых случаев Rulate/Bllate — диапазоны и пагинация, закрытые главы между открытыми, противоречивые дубликаты, неизвестные признаки и последующий HTTP 403. Живая разметка второй страницы получена с HTTP 200; полный повтор через `BookPipeline` на ПК остановился на первом запросе канонического URL по таймауту 120 секунд, до обращения к главам. Все временные файлы проверки удалены. Позднее владелец подтвердил сохранение доступной части на Android, см. следующий результат.

### Успешный повтор на устройстве, 11:47–11:50 МСК

Журнал от 13 ноября: Pixel 9a, Android 17, WebView 157, `0.2.1-alpha.codex.2`, коммит `751f629`, стандартная задержка (позиция 2). Загружены 158 глав; 456 записей оглавления пропущены с явным предупреждением об отсутствии доступа, без запроса текста. Ядро завершилось за 182 839 мс. В MediaStore сохранены EPUB 1 311 597 байт и отдельная обложка 414 995 байт; копирование заняло 269 мс. Финал — «Готово» и предупреждение о 456 пропусках. HTTP 403, оборвавшего предыдущую попытку, в этом проходе нет.

Это подтверждение сохранения доступных глав, а не получения закрытых частей. Кэш-попаданий в журнале нет, поэтому повторное использование кэша на устройстве этим отчётом не подтверждается. Положения 2 в журнале и 4 на позднем скриншоте относятся к разным моментам времени.

Дополнительно обычными публичными запросами получены все 7 страниц оглавления: 609 записей, из них 451 с явным запретом скачивания и 158 без такого запрета. Это подтверждает возможность избежать лишних запросов в описанном сценарии, но не гарантирует отсутствие HTTP 403 по другим причинам.

F9 реализована для текстов Rulate/Bllate. При повторе заново собирается оглавление; старый текст используется только при однозначном текущем доступе. Конфликтная строка или дубликаты с разным доступом проверяются через API. Кэш разделяет сайт, книгу, главу и аккаунт; пароли/cookies не сохраняются. Ограничения: 64 МиБ, 2048 записей, 2 МиБ на запись. По дополнительному запросу 13 ноября кэш перенесён в постоянный приватный каталог с миграцией прежних записей; настройка отключения, семидневный срок и удаление после успеха убраны. Обычное обновление APK сохраняет главы; при заполнении вытесняются давно не использованные записи. Изображения могут загружаться заново. Повреждение кэша и ошибки диска приводят к предупреждению и обычному запросу текста. Проверка обновления моделируется на уровне данных, физическое обновление телефона в этой сессии не выполнялось.

## Litnet: серия «Четверо за спиной»

13 ноября карточка [книги 451957](https://litnet.com/ru/book/chetvero-za-spinoi-b451957) вернула HTTP 200 и серию «Миргородские былины» в прежнем HTML-селекторе. API метаданных сообщил `cycle_id=38860`, `cycle_priority=1`. Поэтому исходную потерю серии в присланном FB2 воспроизвести не удалось. Отдельная попытка полного загрузчика без пользовательского аккаунта остановилась на проверке 18+ до получения серии.

При недоступности необязательной HTML-страницы серии теперь записывается предупреждение, книга может сохраниться без серии. HTTP-ошибки обязательного API остаются ошибками скачивания. Номер серии берётся только из положительного значения API; HTML-сущности в ссылке декодируются. Регрессии проверяют название и номер отдельно, отсутствие серии, HTTP 403/404/503.

## Диагностика TLS: сравнение VPN

В двух отчётах Pixel 9a / Android 17 от 13 ноября использована одна сборка `91644c6`. В первом штатное соединение не прошло для BooksTime, FictionBook, Boovell, Libking и Litres, но отдельные пробы TLS 1.2 получили HTTP-ответы. После смены VPN штатные соединения с этими пятью сайтами прошли, общих ошибок стало 0 вместо 5. Это указывает на зависимость от сети/маршрута; конкретный механизм по журналам не установлен.

Сценарий `2026-11-13.1` показывает HTTP-статус дополнительной пробы TLS 1.2 в кратком отчёте и отдельный счётчик в сводке. Ошибка штатного подключения сохраняет статус FAIL: обычный загрузчик автоматически на TLS 1.2 не переключается. Ficbook в отдельном отчёте получил HTTP 403 на книге без входа; открывающаяся главная страница не подтверждает доступ к книге. F8 в эту работу не входит.

## Скриншот настроек и обычный Material Design 3

У слайдера использовались класс и padding текстового поля, поэтому родная полоса оставляла лишнее место после крайнего положения. Заменено отдельным блоком: трек 4 px, круглый бегунок 20 px, область касания 48 px, четыре позиции и подпись без рамки. Основание — обычные токены [M3 slider v0.192](https://raw.githubusercontent.com/material-components/material-web/main/tokens/versions/v0_192/_md-comp-slider.scss) и [M3 switch v0.192](https://raw.githubusercontent.com/material-components/material-web/main/tokens/versions/v0_192/_md-comp-switch.scss), без перехода на Expressive. Длинные подписи настроек переносятся. Фокус слайдера больше не ошибочно распознаётся как открытие клавиатуры и не прячет навигацию.

Цвета слайдера берутся из тех же ролей M3, что кнопки и переключатели. Системная палитра перечитывается после возвращения из фона; явный выбор темы сохраняется. [Dynamic Colors доступны с Android 12](https://developer.android.com/develop/ui/views/theming/dynamic-colors), на Android 8–11 используются фиксированные светлая/тёмная палитры. Режимы AMOLED и e-ink сохраняются.

Проверено 48 сочетаний в браузерном preview Edge 157: ширины 320/410 CSS px, четыре положения, светлая/тёмная fixed/dynamic, AMOLED/e-ink. Горизонтального переполнения нет, крайние положения совпадают с концами трека; минимальный контраст вспомогательного текста в проверенной матрице 8,04:1. Отдельно проверены Home/End/ArrowLeft и фокус. Восемь JS-регрессий выполняются также в CI. Preview использует CSS/JS проекта и разметку блока настроек, а состояние Razor заменено тестовыми значениями; это не запуск Android-приложения.

Android 8 проверен на уровне поддерживаемых API/синтаксиса: min API 24 и ARM32/ARM64 сохранены, новые CSS/JS не требуют возможностей новее Chrome 94. Android 8 по-прежнему требует подходящий обновлённый WebView; физического устройства Android 8 в этом прогоне не было.

После исправлений безопасности прошли 362 теста ядра, 99 Android-служб и 30 тестов релизных скриптов. Офлайн-проверки используют только фиктивные токены: чужой сервер картинки не получает заголовки авторизации, cross-origin 307/308 не получает тело входа, старые журналы очищаются перед экспортом. Кнопка «Очистить логи» удаляет внутренние журналы и защищена от старта нового задания и поздних строк отменённого задания.

Старый код сравнивал очищенное название с исходным фрагментом без нормализации, поэтому заголовок оставался в тексте и повторно добавлялся сборщиком.

Теперь сравнивается весь структурный блок `chapter` на позиции оглавления, с нормализацией HTML-сущностей и пробелов. Обычный абзац с таким же текстом не удаляется. Граница последней выбранной главы берётся из полного оглавления: выбранный диапазон больше не захватывает остаток книги.

Живая загрузка создала FB2 и EPUB без предупреждений. Независимая проверка: 26/26. В обоих форматах три главы без повторных заголовков; текст всех глав совпадает с исходными блоками после нормализации пробелов. FB2 проходит XSD, EPUB — проверки архива, XML, manifest/spine и внутренних ссылок.

## Два файла и emoji

В старом журнале было включено отдельное сохранение изображений, и обложка попадала в `Images/Cover.jpg` независимо от переключателя «Обложка отдельным файлом». Поэтому результат «2 файла» означал EPUB и обложку. По дополнительному сообщению 13 ноября этот обход настройки исправлен: выключенная отдельная обложка не экспортируется даже вместе с дополнительными изображениями. Обложка внутри EPUB/FB2 и обычные иллюстрации сохраняются. Сообщение различает файлы книги и дополнительные файлы.

Emoji сохраняются в метаданных и текстах FB2/EPUB. Подтверждён отдельный дефект длинного имени: обрезка по UTF-16 могла оставить половину символа. Обрезка теперь сохраняет целую графему, включая составные emoji, модификаторы и флаги, в пределах прежнего ограничения длины.

## Дополнительные настройки и проверка версий, 13 ноября

«Сохранить журнал скачивания и запуска» теперь полноценная тональная кнопка рядом с действиями диагностики. Таймаут одного сетевого запроса переключается слайдером 60/120/240/свой, по умолчанию 120 секунд; прежнее значение сохраняется. Свой таймаут (5–3600 секунд) запоминается отдельно при переключении пресетов. Объяснение «Пропустить диалог скачивания» скрыто под нативной раскрываемой справкой «?». Убраны двойные отступы вложенных элементов настроек и отладки, длинные подписи кнопок переносятся; общие роли цветов, карточки и обычные размеры M3 сохранены, Expressive не используется.

Проверены 8 JS-тестов и 16 DOM-сценариев: 320/410 px, светлая/тёмная/AMOLED/e-ink, справка закрыта/открыта. Горизонтального переполнения и обрезки кнопок нет; слайдеры и справка доступны с клавиатуры. Computer Use и скриншоты в этом прогоне не использовались. Это проверка браузера на ПК, а не физического Android 8.

Приватное постоянное хранилище соответствует [app-specific persistent files Android](https://developer.android.com/training/data-storage/app-specific): обновление пакета сохраняет данные, удаление приложения — нет. Тест переноса моделирует прежний выключенный preference, миграцию записей v1, удаление временного каталога и новый экземпляр менеджера. Надёжной ревизии текста в текущем оглавлении Rulate/Bllate нет: изменение текста под тем же ID без изменения доступа автоматически не обнаруживается; это ограничение повторного использования, а не подтверждение неизменности книги на сайте.

После правок прошли 371 тест ядра и 115 тестов Android-служб. Проверены перенос старой v1-записи, повтор после ошибки и после полностью успешной загрузки Rulate/Bllate без запросов уже готовых глав, LRU/лимиты и ошибки диска. EPUB3/FB2 проверены с включённой/выключенной отдельной обложкой: встроенные байты обложки сохраняются, иллюстрации и аудиовложения не теряются. Android Debug/Release проверяется в CI; релиз без согласия владельца не публикуется.

На ПК найден старый `E2E-2.9.3-3a81106.apk`: versionCode 430401, API 29+, только ARM64. Здесь 2.9.3 — старая нумерация по ядру, а не более новая версия приложения. Актуальный стабильный релиз — `v0.2.0`, versionCode 437897, API 24+, ARM32/ARM64; официальный APK скачан и его SHA-256 сверён с метаданными GitHub. У обоих пакет `e2e.droid` и один сертификат подписи. Исходная рабочая ветка `1b68207` соответствует `alpha.codex.3` и содержит 45 коммитов после стабильного тега; новые правки добавлены поверх неё. Формат истории и учётных записей не меняется. Новая сборка готовится артефактом Actions без публикации релиза.
