# Проверка новых сообщений тестировщиков

Проверки выполнены 12 ноября 2026 года на ПК тем же `BookPipeline`, загрузчиками и сборщиками, которые использует Android-приложение. Обычный публичный доступ без логина, стандартная задержка 0,6–1,5 секунды. Это не проверка запуска APK на устройстве.

## Rulate: книга 209502

[Пример пользователя](https://tl.rulate.ru/book/209502): две страницы оглавления, 167 уникальных глав. Загрузчик обработал все 167, включая страницу после сотой главы. Сайт предоставил тексты глав 1–51; для 52–167 вернул отсутствие доступа. Эти 116 глав отмечены предупреждениями, в книгу не включены.

Созданы FB2 и EPUB с 51 непустой главой в правильном порядке и обложкой. Независимая проверка: 23/23 — официальная XSD FB2, структура EPUB, CRC архива, manifest/spine, XML, ссылки и изображения. Полный проход занял около трёх минут. На этом примере можно подтвердить проход всего оглавления, но нельзя проверить сохранение более 100 текстов без доступа к закрытым главам.

## Rulate: журнал книги 129557

В присланном журнале [«Лунное путешествие (LN)»](https://tl.rulate.ru/book/129557?Chapter_page=7) остановилось после 100 записей оглавления. Последняя имела название «Часть 95»: номера в названиях повторяются, поэтому они не равны количеству записей.

Текущий загрузчик получил все 609 уникальных записей. Дополнительно проверены настоящие тексты 100-й и 101-й записей. Последняя, 609-я, без входа недоступна. Параметр `Chapter_page` исходной ссылки не ограничивает книгу: сначала собирается полное оглавление, затем применяется диапазон приложения.

Диапазон 100–101 сохранён в FB2 и EPUB без предупреждений. Независимая проверка: 28/28 — обе главы в правильном порядке, FB2 соответствует XSD, EPUB структурно корректен. После удаления служебного абзаца текст совпал с ранее скачанными HTML в обоих форматах при исключении пробельных символов. Все 609 текстов в этой проверке не скачивались.

Ссылка в конце каждой части присутствует в ответе сайта: отдельный `<p>` с URL текущей главы. Очистка удаляет только такой завершающий абзац с точным адресом скачиваемой главы. Другие адреса, авторские подписи, ссылки внутри текста и изображения сохраняются. Общая очистка ссылок других сайтов по этому примеру не выполняется.

## Rulate: полный проход на Android, 13 ноября

Журнал владельца для книги 129557, APK `0.2.1-dev.34`, коммит `91644c6`: 279 попыток глав с 05:14:48 до 05:20:01 МСК. Первые 158 записей обработаны без предупреждений об отсутствии доступа. На 159-й записи — «Часть 154. Том 3. Земля», ID `26108831` — API сообщил об отсутствии доступа; такие ответы повторились 120 раз подряд. Следующий запрос завершился HTTP 403. Генерация EPUB не началась: сборщик вызывается после завершения загрузчика. Это подтверждает прохождение границы 100 глав, но не сохранение полной книги. Причину последнего HTTP 403 журнал не раскрывает.

В публичной разметке второй страницы оглавления подтверждён явный признак: у `26108831` есть `span.disabled` с `title="Вы не можете скачивать перевод этой главы."`, отсутствует активное действие скачивания. Предыдущая запись `26108830` содержит активную кнопку «Получить готовый перевод.» и `download_chapter[]`. Ссылка в названии `/ready_new` есть в обоих случаях, а цена сама по себе не определяет доступ текущего пользователя.

Загрузчик сохраняет этот признак вместе с ID и названием. Диапазон применяется к полному оглавлению, после чего явно недоступные главы пропускаются с предупреждением, без запроса `readyajax`. Противоречивая разметка с активной кнопкой или выбором скачивания проверяется через API. Неизвестные признаки не считаются запретом. Поздний HTTP 403 по-прежнему останавливает генерацию: автоматическое сохранение незавершённой книги и возобновление относятся к отдельной задаче F9.

Проверки исправления: 277 тестов ядра прошли, включая 16 новых случаев Rulate/Bllate — диапазоны и пагинация, закрытые главы между открытыми, противоречивые дубликаты, неизвестные признаки и последующий HTTP 403. Живая разметка второй страницы получена с HTTP 200; полный повтор через `BookPipeline` на ПК остановился на первом запросе канонического URL по таймауту 120 секунд, до обращения к главам. Все временные файлы проверки удалены. Успешное сохранение всей доступной части на устройстве после этой правки пока не подтверждено.

## Litmarket: повтор названий

[«Девочки из прошлой жизни»](https://litmarket.ru/books/devochki-iz-proshloy-zhizni-1): публичный ответ содержит 3 главы и 301 блок текста. В структурных заголовках есть конечные пробелы и переносы. Старый код сравнивал очищенное название с исходным фрагментом без нормализации, поэтому заголовок оставался в тексте и повторно добавлялся сборщиком.

Теперь сравнивается весь структурный блок `chapter` на позиции оглавления, с нормализацией HTML-сущностей и пробелов. Обычный абзац с таким же текстом не удаляется. Граница последней выбранной главы берётся из полного оглавления: выбранный диапазон больше не захватывает остаток книги.

Живая загрузка создала FB2 и EPUB без предупреждений. Независимая проверка: 26/26. В обоих форматах три главы без повторных заголовков; текст всех глав совпадает с исходными блоками после нормализации пробелов. FB2 проходит XSD, EPUB — проверки архива, XML, manifest/spine и внутренних ссылок.

## Два файла и emoji

В журнале включено отдельное сохранение изображений. Даже когда в главах нет иллюстраций, обложка сохраняется как `Images/Cover.jpg`. Поэтому результат «2 файла» означает EPUB и обложку. Теперь сообщение различает файлы книги и дополнительные файлы, а сохранение обложки явно отмечено в журнале.

Emoji сохраняются в метаданных и текстах FB2/EPUB. Подтверждён отдельный дефект длинного имени: обрезка по UTF-16 могла оставить половину символа. Обрезка теперь сохраняет целую графему, включая составные emoji, модификаторы и флаги, в пределах прежнего ограничения длины.

## Регрессии

Локально прошли 217 тестов ядра и 31 тест Android-служб. Новые случаи проверяют границы диапазона Litmarket, нормализацию заголовков, сохранение авторского текста и изображений при очистке Rulate, Unicode в реально сформированных FB2/EPUB и пояснение количества файлов. По результату CodeQL добавлена явная остановка при блоке Litmarket без содержимого: повреждённый ответ не превращается в частично сохранённую главу.
