## Найденная ошибка ЛитРес

Основной отрывок `72130255.fb3` получен с HTTP 200, размер ответа 1 761 129 байт. После него загрузчик запрашивает `67799625.fb3`, получает HTTP 404 и выходит до разбора уже скачанного основного FB3. Это дефект обработки связанных материалов: `linked_arts` обходились даже при `Additional=false`, а ошибка необязательного файла отменяла основную книгу. Тип связанного материала журнал не сообщает; считать его аудио или удалённой книгой только по этому логу нельзя.

Исправлено: выключенные дополнительные файлы больше не запрашиваются; при включённых учитывается выбранный тип. HTTP-ошибка или ошибка чтения/записи отдельного связанного материала даёт предупреждение и не отменяет основной текст. Отмена и ошибка самой основной книги продолжают прерывать операцию. Анонимные аудиоматериалы отмечаются как неподдерживаемые без запросов по текстовому маршруту `.fb3`.

Основной FB3 выбирается до обхода связанных изданий, файлы разных изданий разделены и получают стабильный префикс с идентификатором издания. Дополнение с одинаковым именем `Content-Disposition` больше не перезаписывает основной файл как при разборе, так и при экспорте. Для ошибок JSON API сохранены HTTP-статусы, ответы освобождаются.

Добавлены регрессии: выключенные дополнения, HTTP 403/404/410 дополнения, одинаковые имена файлов с проверкой настоящего экспорта, аудио и выбор типа, авторизованный путь, ошибка ввода-вывода и отмена. Основной HTTP 404 остаётся ошибкой. Локально прошли 647 тестов ядра и 160 тестов сервисов. Исправление ещё не проверено повторно на телефоне.

- **Boosty:** открытый блог отвечает HTTP 200; обход оглавления со штатной задержкой исчерпывает общий лимит 90 секунд (2360–2429). Простое обрезание первой страницы меняло бы порядок глав. Ограниченный сценарий отдельного поста ещё не реализован.
- **Booknet.ua:** отсутствует название серии при известном номере 1 (480); текст и файлы исправны.
- **Jaomix:** эвристика подозревает повтор первого заголовка (1027, 1039). Без содержимого это не подтверждённый дефект.
- **MyBook:** импортирует EPUB целиком — 15 глав вместо одной (1619); структурные проверки файлов проходят.
- **TwilightRussia:** предупреждение относится к успешно исправленной дублированной схеме ссылки (2202); оба формата проверены.
- HTTP 403/429 у других сайтов и HTTP 404 у ресурсов примеров сохранены как отдельные результаты, без заявления об исправности этих загрузок.

Для разбора не требовались повторные сетевые скачивания: использованы присланный журнал, предыдущий прогон и исходники.
