# Litnet, ЛитРес и иллюстрации: жалобы на 0.2.2

## Что подтверждено

Семь журналов `E2E-download-log-20261115-*` относятся к релизу 0.2.2, коммиту `29126a0`.

- `070630`: журнал обрывается после заголовков ответа обложки; завершение задания неизвестно.
- `082957`, `093256`: после HTTP 200 приложение ждёт тело страницы серии, затем повторно загруженной
  обложки, до таймаутов 240/400 секунд. Это не доказывает зависание оглавления.
- `095859`, `100824`: ожидание тела обложки/страницы серии при таймауте 1000 секунд; пользователь отменил задания.
- `102159`: обложка и оглавление получены, таймаут при чтении первой пачки текстов глав; стек содержит HTTP/2 и Brotli.
- `115802`: доступные главы прочитаны, затем загрузка оборвалась на первой закрытой главе.

API Litnet сообщает `access=false` для закрытых глав. Модель не читала это поле, а строгая проверка
пустого текста, добавленная в 0.2.2, стала отклонять весь ознакомительный фрагмент.
HTTP 429 на отдельном скриншоте — реальное ограничение сайта; гарантировать его исчезновение нельзя.

Отдельного журнала ЛитРес нет. Найдена воспроизводимая причина показанного предупреждения HTTP 403:
общий HTTP-обработчик записывал предупреждение до завершения операции, хотя следующий штатный маршрут
ЛитРес мог вернуть полную книгу. Точный маршрут в пользовательском случае неизвестен.

## Изменения

- Litnet применяет выбранный диапазон, затем исключает только явно закрытые главы. Доступный фрагмент
  сохраняется с предупреждением. Неизвестный доступ, отсутствующий текст, повреждённый ответ и HTTP 429
  остаются ошибками. Покупки и права аккаунта приложение не меняет.
- Карточка и полная загрузка Litnet используют одни полученные метаданные, серию и исходник обложки.
  Каждая книга владеет отдельным временным файлом обложки; удаление превью не удаляет обложку результата.
  Кэш существует только в экземпляре загрузчика и сбрасывается при новой авторизации или смене книги.
- Запрос изображения идёт на настоящий адрес CDN, без подмены URI доменом основного сайта.
  Для Litnet выбран HTTP/1.1, получение необязательной серии ограничено 30 секундами, включая задержки.
  Это транспортная правка по журналам; они сами по себе не доказывают причину зависания именно в HTTP/2.
- Промежуточные HTTP 401/403/429 остаются в подробном журнале. Предупреждение пользователю формирует
  загрузчик по результату операции. Настоящие ошибки и предупреждения о неполном результате не подавляются.
- ЛитРес при HTTP 408/429/5xx прекращает основную загрузку, не подменяя сетевой сбой ознакомом.
- Импорт EPUB и FB3 ЛитРес учитывает отключение иллюстраций, сохраняя встроенную обложку EPUB/FB2.
  Подписи переключателей уточнены; отдельный файл обложки по-прежнему независим.
- Карточка предупреждений не сообщает об успешном сохранении при провале скачивания и не объявляет
  книгу неполной из-за любого предупреждения, например отсутствующей серии.

Общие изменения в ядре нужны для корректной оценки результата HTTP и импорта EPUB; ограничения сайтов
обрабатываются в соответствующих загрузчиках. Лимит манги и отдельная папка журналов сохранены.

## Проверки и границы результата

- 679 тестов ядра, 277 тестов Android-сервисов и 8 проверок интерфейса прошли.
- CoreSmoke собран: общий с Android конвейер, проверка сертификатов включена.
- Исходные книги Litnet `619747` и `621406` остановились на требовании входа для 18+ за примерно 4 секунды.
  Логины пользователей не использовались; покупки этих аккаунтов не проверены.
- Открытый пример `https://litnet.com/ru/book/otbor-dlya-temnoi-vedmy-b51246`:
  8 доступных глав из 21, 13 закрытых не запрашивались. За 13,89 секунды созданы FB2 (349771 байт)
  и EPUB (311168 байт), обложка 25335 байт сохранена, иллюстрации отключены.
  Оглавление и число глав готовых файлов проверены. Метаданные и обложка загружены по одному разу,
  все 7 HTTP-запросов использовали HTTP/1.1. Эвристика обнаружила возможный повтор заголовка в тексте;
  это отдельное форматирование, не ошибка скачивания.
- Реальный телефон и скачивание купленной книги с пользовательским аккаунтом этим прогоном не проверены.
