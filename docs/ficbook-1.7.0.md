# Загрузчик Ficbook: мобильный API 1.7.0

Изменения от 14 ноября 2026 года основаны на предоставленном разборе встроенного клиента Ficbook 1.7.0 (build 305) и проверке публичных запросов.

## Получение книги

- Карточка, автор, аннотация и обложка остаются из HTML `/readfic/{slug}`.
- Оглавление: `POST /api_mobile/fanfic_parts`, JSON `{"fanfic_slug":"..."}`.
- Каждая выбранная глава: `POST /api_mobile/fanfic_part_text`, JSON `{"part_id":123}`. Ответ — `result=true` и строка `data`.
- Первый сервер — `https://fanficlets.xyz/`, резервный — `https://ficbook.net/`. Ссылки в готовой книге остаются на основном сайте; входные ссылки зеркала тоже распознаются.
- При сетевом сбое, таймауте, HTTP 5xx или `Cf-Mitigated: challenge` запрос один раз переносится на резервный сервер. Уже полученные главы внутри текущей загрузки не запрашиваются повторно. Недоступный сервер до конца этой загрузки повторно не проверяется.
- Обычные 401/403/404/429 и `result=false` останавливают загрузку. Отмена пользователем не переключает зеркало. Cookies остаются в штатном контейнере со своим доменом.
- Идентификаторы глав берутся только из ответа API. Список упорядочивается по `order_num`, повторы ID убираются, явно неопубликованные главы пропускаются. Пропуски в нумерации не заполняются. Выбор по номеру или названию применяется к доступному оглавлению.
- Старый числовой slug, например `10003242`, передаётся как есть. Внутренний числовой ID современной работы не заменяет её UUID-slug.

## Содержимое и ошибки

Строка API может содержать обычный текст или разметку. Сохраняются абзацы, базовое оформление и текст сносок. Атрибуты, активные ссылки и обработчики из разметки не переносятся; неизвестные теги сохраняются буквальным текстом. Пустые и некорректные ответы не выдаются за готовую книгу. Тело ответа и данные сеанса не пишутся в сообщения об ошибках.

Общие сборщики EPUB и TXT исправлены вместе с загрузчиком: повторное декодирование HTML удаляло или искажало буквальный текст в угловых скобках. Проверки выполняются на готовых файлах FB2, EPUB и TXT, включая форматирование и экранированные теги.

Наличие скрипта `/cdn-cgi/challenge-platform/scripts/precursor/main.js` на HTML-странице само по себе не означает запрет: он есть и в успешной карточке книги. Признаком Challenge Page служит заголовок `Cf-Mitigated: challenge`.

## Проверка на сайте

Проверен штатный `BookPipeline` на Windows .NET 10, с обычной проверкой сертификатов, без входа, без пользовательских cookies, без прокси, с задержкой 0,6–1,5 секунды:

| Пример | Результат |
| --- | --- |
| `https://ficbook.net/readfic/019e5fb6-20ea-7b15-8e5b-5706e6ee13a8` («Люцид») | Все 23 доступные главы; EPUB 707006 байт, FB2 1165987 байт, TXT 733402 байта |
| `https://ficbook.net/readfic/10003242` («Миссия») | Выбранные первые две главы из оглавления на 45 глав; EPUB 200780 байт, FB2 38809 байт, TXT 33773 байта |

FB2 разобраны как XML, проверена структура EPUB; временные книги удалены после проверки. Пройдены все 411 тестов `Elib2Ebook.DomainServices.Tests`. Из них 37 сценариев загрузчика Ficbook и 3 проверки готового файла FB2/EPUB/TXT: 105 глав, диапазоны, пропуски нумерации, недоступность серверов, отмена, ошибки API и безопасный экспорт текста.

Это не проверка на физическом Android-устройстве и не гарантия постоянной доступности зеркала. Premium `all-parts`, экспорт сайта `/fanfic_download/` и импорт/сохранение пользовательских сессий не добавлялись.
