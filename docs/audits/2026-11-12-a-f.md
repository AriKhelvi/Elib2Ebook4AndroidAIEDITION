## Проверки и обоснование исправлений

Изменены семь исходных файлов: AuthorTodayGetter, BookstabGetter, BookRiverGetter, BooksYandexBooksGetter, BoostyGetter, DarkNovelsGetter, FreedomGetterBase. Причины находятся в общем коде загрузчиков, поэтому исправление только Android UI оставляло бы тихую потерю контента.

Добавлены `AuthorTodayAuditTests`, `BooksYandexAuditTests`, `BoostyAuditTests`, `HttpChapterAuditTests` и `AfAuditSupport` в `tests/Elib2Ebook.DomainServices.Tests/Getters/`. Всего 16 сценариев: пакеты 205 глав, порядок, диапазон, пропавшие ID, 205 эпизодов, 110 постов, повтор страницы/cursor, preview без полной загрузки, ошибки 400/403/429 и предупреждения об отсутствии доступа. Тесты переданы корневому агенту для единого запуска; отдельная параллельная сборка не запускалась.

Не решены догадками: окончание страниц BookInBook; сокращённые пагинаторы Bookstime/FictionBook; неполнота одного ответа HTML/API у других перечисленных загрузчиков; диапазон у сериалов Яндекс Книг; детали пропуска частей Ficbook без ссылки. Для них нужны конкретные ответы/страницы длинных книг.
