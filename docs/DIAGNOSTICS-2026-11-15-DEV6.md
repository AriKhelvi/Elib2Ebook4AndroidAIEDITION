## ЛитРес: исправление подтверждено

Основной отрывок `72130255.fb3` получен с HTTP 200, размер 1 761 129 байт (1382–1386). Связанный ресурс `67799625`, который раньше прерывал загрузку, не запрашивался. FB2 и EPUB созданы (1413, 1416), структурные проверки и внутренние ссылки исправны (1418–1446).

Это ознакомительный отрывок, а не подтверждение полной книги. В нём распознаны 14 секций, десять без содержимого; главы V–XIV исключены с предупреждениями (1390–1410), сохранены четыре содержательные главы. Журнал не доказывает потерю доступного текста парсером. Проверка авторизованной полной книги этим прогоном не выполнялась.

Фраза итоговой диагностики «сайт мог вернуть книгу целиком» была слишком предположительной для отрывка. Она заменена нейтральным сообщением о числе глав и неподтверждённой полноте книги.

## Bookuruk: выявлена ошибка результата

Карточка, оглавление и первая глава получили HTTP 200 (591–609). Но FB2 содержит две ссылки на изображения, одну без соответствующего `binary`, и не содержит полезного содержимого после заголовка главы (625–627). Статус EPUB «OK» не доказывает наличие текста: его прежняя проверка могла считать текст внутри `script`, `style` или `template` полезным содержимым (630–638).

Код Bookuruk принимал контейнер `read-area` без очистки служебных узлов. Воспроизводимый случай с одним CSS/JavaScript проходил в загрузчик, затем FB2 удалял служебные узлы. Точный HTML ответа из прогона не сохранён, поэтому это установленный дефект обработки, но не доказанная причина именно этой страницы. Отдельная ограниченная анонимная проверка карточки получила HTTP 429 и была остановлена без повторов; HTML главы не получен.

Другая воспроизводимая проблема — изображения в аннотации, для которых загрузчик не создаёт файлы: они могут превратиться в FB2-ссылки без `binary`. Происхождение отсутствующей ссылки в конкретном журнале без HTML установить нельзя.

Правка ограничена очисткой служебных узлов Bookuruk, отказом от сохранения пустой главы, удалением необработанных изображений из аннотации и структурной отладкой без текста книги, атрибутов или реквизитов доступа. EPUB-проверка отдельно исключает служебные поддеревья из полезного содержимого. Это защита от повреждённого результата; восстановление скачивания исходной главы на телефоне ещё не подтверждено.

## Остальные ограничения

- **Remanga:** прежний первый URL страницы теперь получил HTTP 200 (2026–2031). Девять страниц и обложка успешно скачаны; все 13 отправленных запросов получили HTTP 200. Десятая страница не успела отправиться: отмена в очереди, `network_ms=0` (2072–2077). Около 78 секунд из общего лимита 90 секунд ушло в очередь при интервале 5–10 секунд. Полное число страниц неизвестно, их не меньше десяти. Сборка и проверка CBZ не завершены.
- **Neobook:** прежний транспортный таймаут первого запроса — около 60 секунд без HTTP-ответа, ожидание HTTP/2-соединения (1716–1723). Первопричина не установлена.
- **Boosty:** получены десять страниц API оглавления, следующая отменена в очереди по общему лимиту 90 секунд (2505–2555). Ограниченный сценарий отдельного поста ещё не реализован.
- Предупреждения Booknet.ua о серии, Jaomix о возможном повторе заголовка, MyBook о полном импорте EPUB и TwilightRussia об исправленной схеме ссылки повторяют прошлый прогон.

Новый сценарий диагностики: `2026-11-15.2`. Полный повторный сетевой аудит сайтов не выполнялся.
